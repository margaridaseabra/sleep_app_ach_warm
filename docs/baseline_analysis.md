# Baseline sleep analysis

This folder documents the reproducible baseline sleep-analysis pipeline used for the expanded APP/PS1 and WT cohort.

## Source of truth

Run the pipeline in this order from MATLAB at the repository root:

```matlab
run('pipelines/run_00_prepare_data.m')
run('pipelines/run_01_sleep_architecture.m')
run('pipelines/run_baseline_complete.m')
run('pipelines/run_06_export_baseline_prism.m')
```

`run_baseline_complete.m` is the single source of truth for baseline state occupancy, bout microarchitecture, fragmentation, survival, cohort comparisons, and leave-one-mouse-out sensitivity.

## Analysis windows

- `ZT3_9`: common continuous first 6 h. Use as the primary overall baseline comparison because all 16 mice contribute the same biological interval and bouts remain continuous across the ZT6 boundary.
- `ZT3_6`: first 3 h. Primary time-resolved window.
- `ZT6_9`: second 3 h. Primary time-resolved window.
- `WHOLE`: entire available baseline recording. Use as a sensitivity analysis because recording duration differs among mice.
- `ZT9_12`: third 3 h. Treat as exploratory when coverage is incomplete.

Fixed windows require at least 95% valid scored coverage. Wake bouts <=15 s are reclassified as micro-arousals (MA).

## Generated analysis outputs

The main analysis writes to:

```text
outputs/sleep_architecture/baseline_complete/
```

This folder contains intermediate/result tables and MATLAB figures and is intended to remain git-ignored because it can be regenerated.

## Prism-ready figure data

`run_06_export_baseline_prism.m` writes lightweight figure-source data to:

```text
results/prism/baseline/
```

These CSVs are intended to be committed to GitHub so the exact values used for final Prism figures are versioned.

### `mousewise/`

One row = one mouse. Columns contain mouse metadata plus:

```text
WHOLE, ZT3_9, ZT3_6, ZT6_9, ZT9_12
```

Files include:

- `state_percent_WK.csv`
- `state_percent_NREM.csv`
- `state_percent_REM.csv`
- `state_percent_MA.csv`
- `bout_mean_duration_<STATE>.csv`
- `bout_median_duration_<STATE>.csv`
- `bout_rate_per_h_<STATE>.csv`
- `fragmentation_NREM.csv`
- `fragmentation_REM.csv`

Blank cells mean that the mouse/window did not pass the primary coverage criterion or the metric was unavailable.

These files are the preferred source for Prism dot plots, individual-mouse plots, and genotype comparisons.

### `survival/`

One file per cohort view x analysis window x state, for example:

```text
survival_all_ZT3_9_NREM.csv
survival_all_ZT3_9_REM.csv
survival_thesis_ZT3_9_NREM.csv
survival_new_ZT3_9_NREM.csv
```

Each file contains four columns:

```text
WT_time_s, WT_survival, APP_time_s, APP_survival
```

These are the exact mouse-balanced Kaplan-Meier step coordinates from MATLAB. In Prism, import them into an XY table as two independent XY data sets. Do not rerun an unweighted Prism survival analysis and expect the same curve/statistics, because the MATLAB curves deliberately give each mouse equal total weight.

### `stats/`

Contains the statistics generated by MATLAB:

- Welch APP vs WT tests
- genotype x cohort models
- clustered Cox survival models
- genotype x cohort Cox models
- mouse-balanced KM medians
- leave-one-mouse-out survival sensitivity

The Cox p-values and confidence intervals reported in figures/text should come from these files, not from a separate unweighted Prism survival test.

## Cohorts

The configuration files in `config/` define mouse identity, genotype, sex where known, cohort, session identity, and source files. The historical cohort is stored internally as `thesis`; Prism exports relabel it as `original` for figure readability.

## Git policy

Commit:

- `config/`
- `pipelines/`
- `docs/`
- `results/prism/baseline/`

Do not commit raw recordings, standardized per-second score files, or regenerable `outputs/` directories.
